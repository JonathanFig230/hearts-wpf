# Hearts (Windows Desktop)

A WPF Hearts card game for Windows.

## ▶ [Download & Run](https://github.com/JonathanFig230/hearts-wpf/releases/latest/download/HeartsWpf.exe)

Click the link above to download `HeartsWpf.exe`, then double-click it to play. No install required (Windows may show a SmartScreen warning since the exe isn't code-signed — click "More info" then "Run anyway").

## Build from source

Requires the [.NET SDK](https://dotnet.microsoft.com/download).

```
git clone https://github.com/JonathanFig230/hearts-wpf.git
cd hearts-wpf
dotnet run
```
